# 前端开发环境

## 安装稳定版本NodeJS

```
brew install node@22
```

## 安装yarn工具

```
npm install -g yarn
```

后续使用命令行工具主要是yarn

### 查看yarn源配置

```
yarn config get registry
```

### 修改源【建议用官方就行】

```
yarn config set registry https://registry.npm.taobao.org
```

## 启用自动格式化

创建文件 ``.vscode.settings.json``

```json
{
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": {
    "source.fixAll": "explicit"
  }
}
```



## 配置 .editorconfig

安装插件 ``EditorConfig for VS Code``

配置内容如下：

```
# https://editorconfig.org/

root = true

[*]
charset = utf-8
indent_style = space
indent_size = 2
end_of_line = lf
insert_final_newline = true
trim_trailing_whitespace = true
```

## prettier

代码格式化工具

### 安装

```
yarn add prettier -D
```

### 安装插件

Prettier - Code formatter

### 配置 .prettierrc.cjs

```js
module.exports = {
  // 120 characters per line
  printWidth: 120,
  // use spaces instead of tabs
  useTabs: false,
  // 2 spaces per tab
  tabWidth: 2,
  // use semicolons
  semi: true,
  // use single quotes
  singleQuote: true,
  // use single quotes for jsx
  jsxSingleQuote: true,
  // use arrow function parens avoid
  arrowParens: "avoid",
  // space before and after brackets
  bracketSpacing: true,
  // no trailing commas
  trailingComma: "none",
};
```
