## 关于switch的一些常识
1. switch 语句中的 case 表达式可以是任意类型
   

2. switch 语句中的case 表达式可以是多个值

```go
switch x ｛
case 1 2, 3:
fmt.Println（"x = 1 or x=2 or x=3"）
}
```

3. switch 语句可以是表达式

```go
switch x + y｛
case 1:
	fmt. Println(“x +y)
case 2:
	fmt.Println(“x +y=2”)
default:
	fmt.Println(“default”)
```

4. case分支默认只执行一个，可用fallthrough继续执行

```go
switch n：= rand.Intn(100) % 5;n｛
case 0, 1, 2, 3, 4:
	fmt.Println(“n =“，n)
	fallthrough // 跳到下个case分支
case 5, 6, 7, 8：
	fmt.PrintIn(“n ="， n) // 99
	fallthrough // 跳到下个case分支
default：
	fmt.Println(“n ="， n)
｝

```
