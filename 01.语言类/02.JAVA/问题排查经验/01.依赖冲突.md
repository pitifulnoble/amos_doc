# 依赖冲突
## 问题定位
当出现 classNotFond, classDefNotFond等 一般都是jar版本冲突导致的。

## 黄金经验
1. 当idea启动和 ``mvn spring-boot:run`` 启动报错不一致时，指关系命令启动的报错。
2. 不要使用idea的版本冲突检查工具，用命令工具 ``mvn dependency:tree > ~/tree``
