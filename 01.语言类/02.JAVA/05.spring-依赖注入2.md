## springboot是如何确定哪些class需要加入到IOC容器中的？

在Springboot的启动类中有个注解@SpringBootApplication，这个注解包含@ComponentScan。

@ComponentScan默认会将当前目录和子目录下的class加入到IOC容器中。

## 策略模式-条件注入特定类

场景，某个接口，有多个实现类。选择性注入其中某个类。

### byname或@Qualifier注解(不推荐)

在DI注入时，使用SpringBoot的ByName选择机制，或者使用@Qualifier注解

```java
@Autowired
@Qualifier("irelia")
private ISkill irelia
```

### 只在IOC容器中注入一个具体实现(可以使用)

注释或删除不需要类的@Component注解，让IOC容器中只有一个具体对象可以注入

### 优先级注释@Primary

可以选择某个具体实现类，加上@Primary注解。让它作为高优先级注入

```java
@Component
@Primary
public class Diana implements ISkill {}
```

## @Conditional条件注解

### 常规用法

使用@Conditional条件注解和Contition接口

#### 使用@Configration方式加入IOC容器

@Configration可以用在@Configration上，也可以用在@Component上。这里选择@Configration来演示

```java
import com.amos.amosproject.hero.condition.DianaCondition;
import com.amos.amosproject.hero.condition.IreliaCondition;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Conditional;
import org.springframework.context.annotation.Configuration;

@Configuration
public class HeroConfig {
    @Bean
    @Conditional(DianaCondition.class)
    public ISkill diana() {
        return new Diana();
    }

    @Bean
    @Conditional(IreliaCondition.class)
    public ISkill irelia() {
        return new Irelia();
    }
}
```

1. @Configuration和@Bean是以前提到过，加入容器的常规方式
2. @Conditional则是给加入IOC容器添加了条件限制

具体条件限制如下：

#### 条件类的实现

```java
import org.springframework.context.annotation.Condition;
import org.springframework.context.annotation.ConditionContext;
import org.springframework.core.type.AnnotatedTypeMetadata;

public class DianaCondition implements Condition {
    @Override
    public boolean matches(ConditionContext context, AnnotatedTypeMetadata metadata) {
        return false;
    }
}

public class IreliaCondition implements Condition {
    @Override
    public boolean matches(ConditionContext context, AnnotatedTypeMetadata metadata) {
        return true;
    }
}
```

在这个条件类中，只有Irelia是返回true，所以IOC容器中，只有一个ISkill实现对象。

#### 其他java class

```java
public interface ISkill {
    public String q();
}

public class Diana implements ISkill {
    @Override
    public String q() {
        return "Diana q";
    }
}

public class Irelia implements ISkill {
    @Override
```

## 成品条件注解ConditionalOnProperty的使用

ConditionalOnProperty从配置文件application.property中通过配置来决定是否注入IOC容器

```java
import org.springframework.boot.autoconfigure.condition.ConditionalOnProperty;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class HeroConfig {
    @Bean
    @ConditionalOnProperty(value = "hi.hero", havingValue = "diana")
    public ISkill diana() {
        return new Diana();
    }
    @Bean
    @ConditionalOnProperty(value = "hi.hero", havingValue = "irelia")
    public ISkill irelia() {
        return new Irelia();
    }
}
```

application.property中定义：

```
spring.application.name=amosProject
hi.hero=diana
```

最终IOC容器只会加入diana对象，而Irelia不会加入。



### 其他condition成品注解

```sh
@ConditionalOnBean 当SpringIOC容器内存在指定Bean时
@ConditionOnClass 当SpringIOC容器内存在指定Class的条件
@ConditionOnExpression 基于SpEL表达式作为判断条件
@ConditionalOnJava 基于JVM版本作为判断条件
@ConditionalOnJndi 在JNDI存在时查找指定的位置
@ConditionalOnMissionBean 当SpringIOC容器内不存在指定Bean时
@ConditionalOnMissingBean 当SpringIOC容器内不存在指定Class的条件
@ConditionalOnNotWebApplication 当项目不是Web项目的条件
@ConditionalOnResource 类路径是否有指定的值
@ConditonalOnSingleCandidate 当指定Bean在SpringIOC容器内只有一个，或者虽然有多个但是指定首选的Bean
@ConditionalOnWebApplication 当项目是Web项目的条件
```
