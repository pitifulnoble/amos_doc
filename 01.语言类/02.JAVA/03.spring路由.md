## 常用Restfull注解

### 包装Restfull注解

```java
import jakarta.servlet.http.HttpServletResponse;
import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.*;

import java.io.IOException;

@Controller
public class BannerController {
    @GetMapping("/test")
    @PostMapping("/test")
    @DeleteMapping("/test")
    @PutMapping("/test")
    @ResponseBody
    public String printBanner(HttpServletResponse response) throws IOException {
        return "hello 你好111";
    }
}
```

GetMapping,PostMapping,DeleteMapping,PutMapping都是限定Method注解



### 通用注解RequestMapping

```java
import jakarta.servlet.http.HttpServletResponse;
import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.*;

import java.io.IOException;

@Controller
public class BannerController {
    @RequestMapping(value = "/test", method = {RequestMethod.GET, RequestMethod.POST})
    @ResponseBody
    public String printBanner(HttpServletResponse response) throws IOException {
        return "hello 你好111";
    }
}
```



## @ResponseBody注解

@ResponseBody放在func上，会将函数返回结果写入到HttpServletResponse

```java
@Controller
public class BannerController {
    @RequestMapping(value = "/test", method = {RequestMethod.GET, RequestMethod.POST})
    @ResponseBody
    public String printBanner(HttpServletResponse response) throws IOException {
        return "hello 你好";
    }
}
```

等同

```java
@Controller
public class BannerController {
    @RequestMapping(value = "/test", method = {RequestMethod.GET, RequestMethod.POST})
    public void printBanner(HttpServletResponse response) throws IOException {
        response.getWriter().write("hello 你好");
    }
}
```



### 可以在class上标注@ResponseBody

如果一个class所有func都要打上@ResponseBody可以移动到class上

```java
@Controller
@ResponseBody
public class BannerController {
    @RequestMapping(value = "/test", method = {RequestMethod.GET, RequestMethod.POST})
    public String printBanner(HttpServletResponse response) {
        return "hello 你好";
    }
}
```

在Class上的@Controller和@ResponseBody可以使用一个注解@RestController替代

等同：

```java
@RestController
public class BannerController {
    @RequestMapping(value = "/test", method = {RequestMethod.GET, RequestMethod.POST})
    public String printBanner(HttpServletResponse response) {
        return "hello 你好";
    }
}
```

## uri分层

通过在Class上用@RequestMapping来将url的前缀提取出来

```java
@RestController
@RequestMapping("/v1/")

    @RequestMapping(value = "/test", method = {RequestMethod.GET, RequestMethod.POST})
    public String printBanner(HttpServletResponse response) {
        return "hello 你好";
    }
}
```
