## Hive复合数据类型

| 数据类型 | 开始支持版本 | 格式                             |
| -------- | ------------ | -------------------------------- |
| array    | 0.14.0       | array<data_type>                 |
| map      | 0.14.0       | map<primitive_type, data_type>   |
| struct   | ~            | struct<col_name: data_type, ...> |

### array实践案例

#### 建立表

```sql
create table stu(
	id int,
  name string,
  favors array<string>
)row format delimited
fields terminated by '\t'   // 同一行字段之间间隔字符
collection items terminated by ',' // 集合元素(当前来说就是array中的元素)之间分隔符
lines terminated by '\n'； // 每行之间的分隔符
```

#### 简单查询

```
select * from stu;
```

| id   | name     | favors                      |
| ---- | -------- | --------------------------- |
| 1    | Zhangsan | ["swing", "sing", "coding"] |
| 2    | lisi     | ["music", "football"]       |



```
select id, name, favors[0] from stu;
```

| id   | name     | _c2   |
| ---- | -------- | ----- |
| 1    | Zhangsan | swing |
| 2    | lisi     | music |



```
select id, name, favors[2] from stu;
```

| id   | name     | _c2    |
| ---- | -------- | ------ |
| 1    | Zhangsan | coding |
| 2    | lisi     | Null   |

### map实践

#### 测试数据

| id   | name     | score                          |
| ---- | -------- | ------------------------------ |
| 1    | Zhangsan | chinese:80,math:90,english:100 |
| 2    | lisi     | chinese:89,math:70,english:88  |

#### 建标语句

```sql
create table stu2(
	id int,
  name string,
  scores map<string,int>
)row format delimited
fields terminated by '\t'   // 同一行字段之间间隔字符
collection items terminated by ',' // 集合元素(当前来说就是array中的元素)之间分隔符
map keys terminated by ':'  // map中每一个entry中key和value之间的连接符
lines terminated by '\n'； // 每行之间的分隔符
```

#### 简单查询

```
select * from stu2;
```

| id   | name     | scores                                 |
| ---- | -------- | -------------------------------------- |
| 1    | Zhangsan | {"chinese":80,"math":90,"english":100} |
| 2    | lisi     | {"chinese":89,"math":70,"english":88}  |



```
select id, name, scores['chinese']as ch, scores['math'] as math from stu2;
```

| id   | name     | ch   | math |
| ---- | -------- | ---- | ---- |
| 1    | Zhangsan | 80   | 90   |
| 2    | lisi     | 89   | 70   |



### struct实践案例

#### 测试数据

| id   | name     | address |
| ---- | -------- | ------- |
| 1    | Zhangsan | bj,sh   |
| 2    | lisi     | gz,sz   |

#### 建标语句

```sql
create table stu3(
	id int,
  name string,
  address struct<home_addr:string, office_addr:string>
)row format delimited
fields terminated by '\t'   // 同一行字段之间间隔字符
collection items terminated by ',' // 集合元素(当前来说就是array中的元素)之间分隔符
lines terminated by '\n'； // 每行之间的分隔符
```

#### 简单查询

```
select * from stu3;
```

| id   | name     | address                               |
| ---- | -------- | ------------------------------------- |
| 1    | Zhangsan | {"home_addr":"bj","office_addr":"sh"} |
| 2    | lisi     | {"home_addr":"gz","office_addr":"sz"} |



```
select id, name, address.home_addr from stu3;
```

| id   | name     | address |
| ---- | -------- | ------- |
| 1    | Zhangsan | bj      |
| 2    | lisi     | gz      |
