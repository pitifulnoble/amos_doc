## count是什么？
函数参数不为NULL的记录数

## count的执行过程
通过在server层为每个count查询维护一个count变量
server 层会循环向 InnoDB 读取记录并进行累加
最后将获取的总记录数返回给客户端



## count（*） count（1） count（字段）对比

性能从高到低：

count（*）=count（1）>count（索引字段）>count（主键）＞count（非索引字段）

1. Count(*)和count(1)等价。优化器会选择非主键索引(二级索引)来遍历取数
2. Count(字段)会按照该字段做统计，有索引走索引，没有索引就全表扫描
